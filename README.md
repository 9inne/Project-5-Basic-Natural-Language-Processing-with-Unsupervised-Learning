# Project 5: Basic Natural Language Processing with Unsupervised Learning

This project applies basic Natural Language Processing (NLP) and unsupervised learning techniques to the **20 Newsgroups dataset**.

I prepared and cleaned the text data, then used **Bag of Words** and **TF-IDF** for text representation. I applied **K-Means clustering** to group documents based on similar topics and analyzed the important terms within each cluster.

I also evaluated the clustering using **Silhouette Score** and **Adjusted Rand Index**, tested the model on unseen documents, and used **Truncated SVD** and **t-SNE** to visualize the clusters.

## Tools Used

- NumPy
- Pandas
- Matplotlib
- Scikit-learn
